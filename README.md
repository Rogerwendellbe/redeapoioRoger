# Rede de Apoio

Página informativa sobre violência doméstica, sinais de alerta e canais de atendimento no Brasil. Projeto de extensão universitária com finalidade educativa e social.

## Estado do projeto

O site é uma página estática em `index.html`. Ele **não contém formulário nem armazena mensagens ou denúncias**. A seção “Canais de ajuda” direciona a pessoa para atendimento por telefone, e a seção “Canais oficiais de denúncia” reúne outras opções.

Se houver perigo imediato, a orientação exibida na página é ligar 190. Para orientação e denúncia, a página indica o Ligue 180. Antes de divulgar o site amplamente, confirme periodicamente os canais, horários, dados estatísticos e orientações jurídicas nas fontes oficiais.

## Como visualizar

Abra `index.html` em um navegador. Não há instalação de dependências nem servidor obrigatório.

## Limites

- Os botões de telefone dependem de um aparelho ou aplicativo capaz de fazer chamadas.
- O botão “Sair rápido” troca a página exibida, mas não apaga o histórico, notificações ou outros vestígios de navegação.
- O projeto não substitui atendimento de emergência, orientação jurídica ou serviço de acolhimento.
